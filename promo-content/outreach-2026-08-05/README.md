## 🚨 注意事项

1. **不要直接复制粘贴原文 HTML** → 每个平台对 HTML 支持不同（Medium 不支持 HTML，要用 Markdown）
2. **每个平台加 canonical 或原文链接** → 避免 Google 判重复内容
3. **Blogger 必发**（权威传递最强）
4. **Medium 慎用 affiliate 链接** → 文末最多 1 个，文中 0 个
5. **Tumblr 不要重复发帖** → 同账号短时间多帖会被降权
6. **每发一篇等 2-3 分钟** → 避免平台判定 spam
